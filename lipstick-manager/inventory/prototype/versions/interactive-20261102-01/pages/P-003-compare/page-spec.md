# P-003 买前查一查

- 目标：购买前查看同色系库存
- 使用角色：已登录的固定管理员。
- 路由：`/compare`（建议路由，无既有代码）。
- 入口：底部导航。出口：P-002/P-001。
- 权限：页面和业务接口均需服务端会话；无公开分享。
- 响应式：375px单列，>=768px适度拓宽，桌面主区不超过1120px；表单最大680px。

## 页面结构
1. 标题“买前查一查”，说明“这次想买什么色系？”
2. “全部”及六色系选择器，每个选项展示名称和辅助文字；移动端可横向滚动，选中具有边框＋勾选。
3. 默认六组固定顺序：裸色、豆沙、橘色、红色、梅子色、棕色；组标题“豆沙色系 · 当前持有3支”。
4. 次级统计：已开封／未开封／状态待补充、已到期数量；到期仍持有但清楚标识。
5. 组内卡片展示实拍、品牌色号、质地、状态与期限；点击看详情。
6. 待分类库存独立入口“有N支待分类”，不计入六色系数量；点击在列表显示待分类。
## 操作与反馈
选择色系只筛选已有库存；无需录入待购新品，不发起模型任务。不出现“不准买”“完全重复”等判断。零库存组显示“尚未记录该色系”；点击“全部”恢复分组。组内最近新增；返回保留色系与滚动。
## 数据和状态
当前持有包含 opened/unopened/unknown，不含 discarded。与 P-001 共享即时数据。加载、空库、零分组、部分待分类、读取失败均有明确反馈。

## 共同约定
刷新读持久数据，保存前改动仅在草稿；卡片回退保留上下文；无权限不展示其他用户数据；状态规范见brief第8节，组件见components/component-spec.md。所有按钮需有真实演示行为，不使用空点击。
