## 1. 背景与约束
帮助拥有多支口红的人整理个人库存、了解期限，并在买前查看同色系数量。核心是六色系库存提醒，不预测个人上唇效果。
来源：最新版PRD和其prototype_handoff、聊天用户的列表参考图。无现成前端页面或Design System可复用；提供新组件规格。继承PRD的个人本地模式等假设，不视为批准上线。

## 2. 范围与演示任务
三页主结构＋一个录入编辑页：P-001列表、P-002详情、P-003买前查看、P-004表单。
必须可点击：导航、新增、上传、模拟识别、候选确认、取消重试、手填、修改色系、日期输入、保存、筛选排序、卡片详情、返回、展开来源、开封、归档恢复、删除确认。
不含：交易、社交、推送、精确识色、跨设备账号、真实AI外传。允许模拟识别／来源，但须明显标注，不能以虚构网址假装官网证据。
任务F-001：空库→新增→整体与底标→识别→候选确认→建议色系→改色系→填开封日→核对期限→保存→详情→列表。
任务F-002：有库存→买前页→豆沙系→查看3支及1支到期→详情→返回保持筛选→归档一支→数量减少→恢复。
任务F-003：无结果／超时→手填→待分类保存→重新编辑确认分类。
任务F-004：查看不同期限区间→展开来源→修改日期→立即重算；冲突提示后修正。

P2：PRD部分摘要仍用“临期”简称；UI一律以最新BR-004具体天数为准，不出现不解释的临期。

## 4. 用户与完成结果
本设备个人用户可查看修改自己的库存。AI只接收主动提交的本次材料且结果须确认。完成结果是保存可信记录、能查同色系数量及期限依据，不等同于减少购买。

## 5. 信息架构与数据
口红柜 ↔ 买前查一查；两页卡片→详情→编辑；口红柜→新增。详情返回原入口；直接打开详情无上下文则返回口红柜。
共享LipstickItem、Draft、AITask、Evidence。草稿／AI建议／持久库存分离。刷新恢复草稿，不自动重发调用；筛选只改变视图。

## 6. 固定业务规则
### 六色系
- `nude` 裸色系：奶茶色、肉桂裸。
- `rose` 豆沙色系：豆沙色、玫瑰色。
- `orange` 橘色系：南瓜色、珊瑚色。
- `red` 红色系：番茄红、正红。
- `plum` 梅子色系：梅子色、葡萄紫。
- `brown` 棕色系：红棕、摩卡、巧克力棕。
一支一个主色系；待分类不计入六组。先AI建议后用户确认，人工修改优先。主色系辅助文字用于理解，不再细分成子类统计。
### 库存
opened/unopened/unknown为当前持有；finished/discarded为历史。已到期仍持有需计数并提示。六组计数互斥；总数还包括待分类。用完／丢弃后数值同步减少，恢复保留原开封日期。
### 日期
O=准确开封日，M=有依据的开封后月数，P=O加M月（月底截到目标月末）。E先用实物明确到期日；无明确E时可由确认的实物生产日期＋准确匹配未开封保质期推算，标注推算。已开封时D=min(P,E)，只有一个则用一个，都无则未知；未开封只用E。
不能用网页其他实物日期替代E；批号不猜日期；未开封保质期不当PAO。未来开封／生产日禁止。O>E或两个E来源冲突需核对，不静默延长。
### 状态展示
| remaining_days | 文案 |
|---|---|
| >180 | 期限尚充裕 · 超过180天（约半年） |
| 91–180 | 剩余91–180天（约3–6个月） |
| 31–90 | 90天内到期 · 可优先安排使用 |
| 1–30 | 30天内到期 · 留意使用期限 |
| 0 | 今日到期 |
| <0 | 已到期 |
| null | 期限待补充 |
所有已知值同时展示真实天数。30天内统计含今日；31–90天筛选为互斥区间。颜色只辅助，不作安全保证。到期不鼓励赶用；无时间基础不画伪进度条。

## 7. 页面与组件规格

### P-001 我的口红柜

- 目标：管理库存与期限
- 使用角色：本设备个人用户。
- 路由：`/inventory`（建议路由，无既有代码）。
- 入口：默认入口／底部导航。出口：P-002/P-003/P-004。
- 权限：仅当前个人数据；无公开分享。
- 响应式：375px单列，>=768px适度拓宽，桌面主区不超过1120px；表单最大680px。

## 页面结构
1. 顶部“我的口红柜”＋“＋录入口红”。
2. 三张概览卡：当前持有、已开封、30天内到期（包含今日）。数值读取同一库存集合，不把维度相加。
3. 状态筛选：全部、已开封、未开封、状态待补充、30天内到期、31–90天到期、已到期、历史；色系筛选；排序控件。
4. 纵向卡片：左侧整体实拍／占位图；右侧品牌色号、色系质地、开封状态、期限状态＋实际剩余天数。主色系标签不等于真实试色。
5. 底部导航“口红柜／买前查一查”。
## 操作与反馈
概览卡点击切换对应筛选；色系和状态取交集；排序默认最近新增，可切截止日期（未知置后）、色系。点击卡片进入详情，保留筛选和滚动位置。筛选不调用AI、不新增数据。首次空库显示“还没有记录口红”及新增／手填；筛选无结果显示“没有符合条件的口红”＋清空筛选。加载骨架不显示临时0。
## 数据和状态
LipstickItem的当前持有集合，历史单独筛选。支持加载、空库、空筛选、有数据、读取失败。失败显示重新读取，不清除已有数据。

## 共同约定
刷新读持久数据，保存前改动仅在草稿；卡片回退保留上下文；无权限不展示其他用户数据；状态规范见brief第8节，组件见components/component-spec.md。所有按钮需有真实演示行为，不使用空点击。


### P-002 口红详情

- 目标：管理一支实物及理解日期依据
- 使用角色：本设备个人用户。
- 路由：`/lipsticks/:id`（建议路由，无既有代码）。
- 入口：列表／买前卡片。出口：原入口／P-004。
- 权限：仅当前个人数据；无公开分享。
- 响应式：375px单列，>=768px适度拓宽，桌面主区不超过1120px；表单最大680px。

## 页面结构
1. 返回＋产品名称＋编辑。
2. 产品整体实拍主图，底标与包装图为缩略证据图；点击可放大。用户可从已上传图片选择封面；无图占位。
3. 品牌、系列、色号；主色系及辅助说明；质地。
4. 期限卡：当前持有状态、开封日期、截止日、剩余天数与分段文案；满足条件时显示时间轴。
5. 折叠“查看计算依据”：开封日＋PAO、明确实物到期日，或生产日期＋未开封保质期；两条截止路径取较早，列出来源。生产日期推算明确标记，不冒充包装标注。
6. 备注与次级管理区。
## 操作与反馈
未开封显示“标记开封”，打开日期输入，支持“不记得”；当前持有显示“标记用完”“标记丢弃”；历史显示“恢复到库存”；删除二次确认，取消无变化。归档后反馈数量已更新，保留历史详情；恢复不重置开封日。
## 动态模块
时间轴仅准确O和有效D且D>=O时显示，未知日期显示“期限待补充”；来源入口仅有Evidence时显示。真实日期冲突回编辑核对，不自行选择延长时间。无整体实拍图时仅可使用用户手动选择、准确匹配且具使用条件的官方图，标注来源；本次Brief不下载产品图。
## 数据和状态
读取id对应条目；不改原始记录。不存在显示“这条记录已不存在”＋返回列表。刷新保留id；直接进入无来源上下文时返回列表。

刷新读持久数据，保存前改动仅在草稿；卡片回退保留上下文；无权限不展示其他用户数据；状态规范见brief第8节，组件见components/component-spec.md。所有按钮需有真实演示行为，不使用空点击。

### P-004 录入／编辑

- 目标：低成本确认信息并入库
- 使用角色：本设备个人用户。
- 路由：`/lipsticks/new 或 /lipsticks/:id/edit`（建议路由，无既有代码）。
- 入口：列表新增／详情编辑。出口：保存到详情／取消回原入口。
- 权限：仅当前个人数据；无公开分享。
- 响应式：375px单列，>=768px适度拓宽，桌面主区不超过1120px；表单最大680px。

## 页面结构
1. 返回、标题，状态“录入”或“编辑”。
2. 拍摄指引：整体图＋底部色号；有包装补拍日期及开封后期限标记。最多3图，10MB/张，JPG/PNG/WebP（继承PRD假设）。选图、预览、移除、指定整体图。
3. “识别信息”主按钮、“手动填写”次按钮；阶段提示＋取消。
4. 仅身份歧义时显示候选卡，品牌＋系列＋色号完整展示；确认身份后继续检索。
5. 表单：识别名称（必填）、品牌系列色号→主色系选择及说明→质地→持有状态→已开封时的开封日／不记得→期限信息→备注。
6. 期限信息支持“实物到期日期”或“实物生产日期＋未开封保质期”，开封后期限独立字段；来源与待核对状态紧邻字段。
7. 底部保存按钮。未知可保留，主色系需确认建议或明确选待分类。
## 操作与反馈
AI建议不直接写库存；用户修改后不得被旧任务覆盖。修改产品身份会使先前资料建议失效，重新查询必须用户触发。手填自定义名称、待分类、unknown即可保存。生产日期不晚于今天；开封日期不晚于今天；日期冲突就地报错并提供核对／清除不确定日期。
保存中禁重复提交；成功跳详情并同步列表、买前计数。失败保留草稿。返回／遮罩／ESC退出编辑均先处理未保存内容（保留草稿或放弃），非编辑弹层可正常关闭。
## AI与隐私状态
本次后续原型默认模拟任务，界面明显标注“演示数据／模拟识别”，不传真实图片。正式AI启用前沿用PRD的服务商与同意前置条件。识别中、检索中、部分成功、候选确认、无结果、失败、超时、取消均可演示；不需要用户等待AI才能手填保存。
刷新恢复草稿但不自动重跑；取消后晚到结果忽略。多标签revision冲突保留工作副本，提示重新载入。

## 8. 状态与异常
| 状态ID | 触发／表现 | 文案与动作 | 数据与恢复 |
|---|---|---|---|
| S-01 initial/empty | 无库存 | 尚未记录→新增／手填 | 不注入假真实库存 |
| S-02 loading | 首次读取 | 骨架，可返回 | 不显示错误0数 |
| S-03 success | 保存完成 | 已保存→详情 | 各页共享更新 |
| S-04 partial | 部分字段识别成功 | 部分信息需补充→手填／保留未知 | 保留可信字段 |
| S-05 no_result | 身份或资料未知 | 未找到可靠资料→重拍／手填 | 不猜期限 |
| S-06 timeout/error | 调用失败或45秒超时 | 查询未完成→重试／手填 | 草稿保留；受PRD调用预算约束 |
| S-07 no_permission | 相机拒绝 | 可从相册选图或手填 | 不申请不相关权限 |
| S-08 long_task | 识别／检索进行中 | 识别中／查询中→取消 | 不用伪精确进度；可手填 |
| S-09 cancelled | 用户取消任务 | 已取消，可继续填写 | 晚到结果忽略；重试新任务 |
| S-10 save_error | 存储容量不足／失败 | 未保存→重试／减少图片 | 不清草稿或覆盖旧值 |
| S-11 stale/conflict | id不存在／revision变化 | 返回列表／重新载入 | 保存编辑副本，禁止静默覆盖 |
| S-12 offline | 网络不可用 | 本地可浏览，资料查询不可用 | 可手填；连接恢复后主动重试 |
| S-13 invalid_dates | 未来日期／来源冲突 | 就地说明，核对或清除不确定项 | 不生成肯定截止日 |
| S-14 refresh/return | 刷新／返回 | 恢复草稿或筛选 | 不重复模型调用，不重复保存 |
模拟入口可提供独立“演示状态”面板，不混入普通用户导航。实际实现前不得将状态面板当产品功能上线。
