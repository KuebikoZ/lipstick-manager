# 公共组件规格

所有组件仅操作当前个人数据；默认白底深色文本，Hover轻微底色变化、Focus可见2px轮廓、Selected用文本＋边框、Disabled注明原因，Loading显示动作文字而非假百分比。下表特殊规则优先。

| ID／组件 | 目的与显隐 | 字段与默认 | 交互与成功／错误反馈 | 响应式 |
|---|---|---|---|---|
| C-001 底部导航 | 一级列表和买前页显示；编辑隐藏 | 当前路由 | 切页保留筛选；选中有文字强调 | 移动固定底部，桌面保留可见导航 |
| C-002 口红卡片 | 有条目时显示 | 图片、名称、色号、色系、质地、状态、期限 | 点详情；无图占位、缺值未记录；不直接修改 | 手机横向卡片，桌面多列 |
| C-003 色系选择器 | 筛选／录入显示 | 六类＋辅助说明；筛选含全部，录入含待分类 | 筛选即时变化；录入确认仅写草稿 | 小屏滚动或两列，不裁文字 |
| C-004 期限标签／时间轴 | 标签始终显示；时间轴仅日期足够 | D、remaining_days、basis | 展开依据；未知提供补充入口；阶段非安全分级 | 换行保留实际天数 |
| C-005 图片输入／证据预览 | 录入显示；详情为只读图集 | 1–3图或空 | 选图、移除、放大；错误就地提示；权限拒绝改选文件 | 触控区44px，预览不横向溢出 |
| C-006 AI任务面板 | 用户发起后显示；未发起隐藏 | phase、result、evidence、unresolved | 取消／重试／手填；部分成功保留字段 | 小屏阶段文字折行 |
| C-007 来源与日期表单 | 来源存在时可展开；日期编辑按状态显隐 | 开封日、PAO、到期日、生产日、未开封保质期 | 字段错误旁提示；用户确认才保存 | 手机单列；来源长URL换行 |
| C-008 对话框与反馈 | 删除、离开草稿、冲突时触发 | 产品名、原因、主次操作 | 删除取消不变；确认后移除；冲突保留草稿；成功toast | 手机底部面板，桌面居中；Focus约束与返回恢复 |

编辑性弹窗不通过遮罩直接丢弃内容；提交中按钮禁用，防重复写入。错误提供动作，不能只显示红点。
